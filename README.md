Token Radar ranks 178 pre-token protocols by an implied value derived from the snapshot's own TVL, growth, age and category, with an 8-step farm plan for each one. The category multiple is the market itself: the median market-cap / TVL ratio of the live-token protocols in each category. The board covers all 40 watchlist protocols plus 138 early ones below the $50M floor.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
